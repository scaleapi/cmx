# Security

cmxc is research code that accompanies a paper. It is not hardened against malicious input; see
"Untrusted input" in [README.md](README.md) for what the decoder checks and what it does not.

To report a security problem, use GitHub's private vulnerability reporting ("Report a
vulnerability" on this repository's Security tab) rather than a public issue. Fixes are made on
the main branch only; there are no maintained release branches.
